## Why This Is In a Technical Training Doc

Technical skills get you in the room. Collaboration skills determine how much impact you have once you're there.

A mid-level engineer who communicates well outperforms a senior engineer who doesn't. Code review is communication. PRs are documentation. RFCs are design conversations. Every technical decision is also a coordination problem.
